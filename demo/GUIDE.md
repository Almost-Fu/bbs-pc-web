## 4. 5–8 分钟演示路线

建议用 **移动 H5（5183）+ PC（5184）+ 管理后台（5185）** 三窗口并排，按下面节奏走。

### 0:00–0:30 开场

- 说明：本机独立库 `bbs_local_codex`，一键启动，四个服务；
- 展示 `start.cmd` 的控制台输出和四个地址；
- 强调只在本机演示，不影响线上数据。

### 0:30–1:20 注册 / 登录

- 移动 H5 打开 5183，进入“我的 / 登录”；
- 优先用 `demo_lin / Demo@2026` 直接登录，保证后面有现成的帖子、消息和关注；
- 也可以现场注册一个新账号（用户名 2–20 位，密码至少 6 位），展示注册后自动登录。

### 1:20–2:20 发帖（含图）

- 移动端首页 → “发布”，或 PC 端 5184 → “发布帖子”；
- 标题示例：`第一次本地彩排：今晚的晚霞`
- 正文示例：`用一键启动器把整套服务跑起来了，发帖、评论、消息都能串起来。`
- 选择任意吧（例如“摄影吧”），上传一张本地图片：
  - `D:\项目\BBS\bbs-app-backend\static\images\bars\bar-1.jpg`
  - 或种子图片 `demo\local\uploads\posts\demo_seed\demo_bar-1.jpg`（运行 seed 后存在）
- 发布成功后进入帖子详情，确认图片正常显示。
- **帖子编辑**：进入自己的帖子点击编辑，修改正文后保存；PC 和移动 H5 的回填、保存返回已验证，原图和互动保留。

### 2:20–3:20 评论、点赞、收藏、关注

## 5. 安全与边界

- 只使用本机独立库 `bbs_local_codex`，不连接线上库，不碰其他库；
- `seed_demo.py` 运行时读取后端 `.env`，但不打印账号、密码或 `.env` 内容；
- 没有库名参数，不能通过命令行改库绕过隔离；
- 不 DROP、不 TRUNCATE、不清库、不 DELETE、不 UPDATE 既有用户资料；
- 不修改后端 / PC / 管理后台源码，不改 `.env`，不安装依赖；
- **不要运行项目原有的 smoke 脚本**：它可能写入非隔离库；本地彩排只用
  `start.cmd` 和 `seed_demo.py`。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 端口 8001/5183/5184/5185 被占用 | 启动器会报错且不会杀外部进程；先释放端口或停掉旧窗口 |
| 5185 没启动 | 检查 `bbs-admin-web\node_modules` 是否存在；启动器不会自动安装 |
| 后台登录提示不是管理员 | 用 `demo_admin` 或 `admin` / `superadmin`，普通 `demo_*` 账号不能进后台 |
| 客服回复像固定话术 | 未配置 DeepSeek 密钥，走本地 FAQ 兜底，属正常 |
| 图片不显示 | 确认用 `start.cmd` 启动（后端 `/uploads`、`/static` 都由 8001 提供） |
| 想重置演示数据 | 不建议清库；重跑 `seed_demo.py` 即可幂等补齐，已存在内容不会被覆盖 |
